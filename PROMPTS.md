# Ключевые промпты и итерации

## 1. Декомпозиция продукта

```text
Спроектируй двухдневный MVP трекера привычек. Определи аудиторию, 6 ключевых User Stories, модель данных localStorage, состояния loading/error/empty и критерии приёмки. Не добавляй авторизацию и облачную БД: нужен реалистичный объём на два дня.
```

Результат был сокращён до одного dashboard, формы привычки, аналитики и AI-разбора. Облачная синхронизация исключена из MVP.

## 2. UI/UX

```text
Создай desktop-first bento dashboard привычек с адаптивной мобильной навигацией. Нужны: прогресс дня, четыре KPI, line chart, donut, недельная таблица отметок, heatmap и AI-панель. Стиль спокойный и профессиональный: тёмно-зелёная основа, лаймовый акцент, без тяжёлых градиентов. Предусмотри light/dark, keyboard focus, empty state и reduced motion.
```

После первой версии были уменьшены визуальный шум и количество декоративных элементов, усилена иерархия главной цели дня.

## 3. Локальная аналитика

```text
Опиши чистые JavaScript-функции для расчёта completion rate, текущей и лучшей серии, сравнения периодов, категорий и heatmap. Учти пустые данные, незавершённый сегодняшний день и переходы месяцев. Все функции должны тестироваться без DOM.
```

Серия считается продолжающейся, если сегодня ещё не отмечено действие, но вчера оно было выполнено.

## 4. AI-анализ

```text
Проанализируй агрегированные показатели привычек. Ответь по-русски и строго по JSON Schema: summary, trend, score, wins, risks, recommendations и motivationalNote. Не делай медицинских выводов, не стыди пользователя. Дай не более трёх коротких измеримых рекомендаций на следующую неделю.
```

Сырой JSON не показывается пользователю: сервер валидирует структуру, а интерфейс раскладывает ответ на визуальные карточки.

## 5. Критическая проверка

```text
Проведи проверку MVP как строгий reviewer: утечки API-ключа, XSS через название привычки, повреждённый localStorage, пустой список, 30 привычек, таймаут API, 401/429/5xx, mobile overflow, keyboard navigation и ошибки консоли. Для каждой найденной проблемы предложи минимальное исправление и regression test.
```

По итогам добавлены экранирование пользовательского текста, ограничение входных данных, demo fallback, CSP, таймауты и автоматические тесты.
