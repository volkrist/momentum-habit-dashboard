# Спецификация продукта

## Продукт

Momentum — персональный dashboard для людей, которым нужен простой визуальный контроль привычек без перегруженных таблиц.

## Целевая аудитория

- специалисты и студенты с несколькими регулярными целями;
- пользователи, которым важна приватность локальных данных;
- люди, которым нужны конкретные выводы, а не сырая статистика.

## Основные User Stories

1. Как пользователь, я хочу добавить привычку за несколько секунд, чтобы сразу начать отмечать прогресс.
2. Как пользователь, я хочу отмечать выполнение по дням и видеть мгновенный пересчёт показателей.
3. Как пользователь, я хочу менять период и категорию, чтобы анализировать отдельные области жизни.
4. Как пользователь, я хочу видеть серии и графики, чтобы понимать устойчивость поведения.
5. Как пользователь, я хочу получить короткий AI-разбор, чтобы выбрать следующий практический шаг.
6. Как пользователь, я хочу сохранить данные между перезагрузками и экспортировать их.

## Модель данных

```js
{
  version: 1,
  settings: {
    range: 7 | 30 | 90,
    category: "all" | "health" | "focus" | "growth" | "balance",
    theme: "light" | "dark"
  },
  habits: [{
    id: string,
    name: string,
    emoji: string,
    category: string,
    targetPerWeek: number,
    color: string,
    createdAt: ISODate,
    entries: { "YYYY-MM-DD": true }
  }],
  insights: object | null,
  updatedAt: ISODate
}
```

## Ключевые UX-решения

- данные показываются карточками и графиками, не JSON;
- главная кнопка — создание привычки;
- текущий день выделяется в недельной сетке;
- любые отметки пересчитывают dashboard без перезагрузки;
- AI имеет явный статус `ДЕМО` или `OPENAI`;
- при проблемах API пользователь всё равно получает локальный анализ;
- управление доступно клавиатурой и имеет понятные `aria-label`.

## Критерии приёмки

- проект запускается одной командой;
- нет ошибок JavaScript в консоли на основном сценарии;
- данные переживают перезагрузку страницы;
- UI корректен на ширине 375, 768 и 1440 px;
- API-ключ отсутствует во frontend и репозитории;
- отсутствие ключа, таймаут и rate limit не ломают интерфейс;
- тесты проходят командой `npm run verify`.
