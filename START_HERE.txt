MOMENTUM — БЫСТРЫЙ СТАРТ
=========================

1. Распакуйте архив.

2. Откройте в Cursor всю папку ai-habit-dashboard.
   Корень проекта — это папка, внутри которой лежит package.json.

   Пример полного пути в Windows:
   C:\Users\ВАШЕ_ИМЯ\Downloads\ai-habit-dashboard

3. Запустите встроенный терминал Cursor и выполните:

   npm run dev

4. Откройте в браузере:

   http://127.0.0.1:4173

Без API-ключа проект уже полностью работает в демонстрационном режиме.


КАК ПОДКЛЮЧИТЬ OPENAI ПОЗЖЕ
============================

Создайте файл с именем .env.local прямо рядом с package.json.

Пример полного пути в Windows:
C:\Users\ВАШЕ_ИМЯ\Downloads\ai-habit-dashboard\.env.local

Вставьте в него:

OPENAI_API_KEY=ВАШ_НОВЫЙ_КЛЮЧ
OPENAI_MODEL=gpt-5.6

Сохраните файл и перезапустите npm run dev.

Важно:
- файл должен называться именно .env.local, а не .env.local.txt;
- используйте новый ключ; ключ, который уже публиковался или отправлялся в чат,
  нужно отозвать;
- не добавляйте .env.local в GitHub — он уже внесён в .gitignore.
