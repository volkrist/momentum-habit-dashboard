# Сценарий презентации — 15 минут

## 1. Live Demo — 5 минут

1. Показать главную: прогресс дня, KPI и графики.
2. Отметить привычку — все показатели меняются сразу.
3. Переключить период и категорию.
4. Добавить новую привычку через форму.
5. Обновить страницу и показать сохранение localStorage.
6. Запустить AI-анализ и показать карточки рекомендаций.
7. Переключить мобильный viewport и тёмную тему.

## 2. Процесс — 5 минут

- Сначала зафиксированы аудитория, User Stories и границы двухдневного MVP.
- UI собран без обязательных runtime-зависимостей: меньше рисков, быстрый запуск.
- Аналитика вынесена в чистые функции и покрыта тестами.
- OpenAI подключён через серверный endpoint, ключ не виден клиенту.
- Structured Outputs решает проблему непредсказуемого JSON.
- При отсутствии API приложение не ломается и использует детерминированный demo-анализ.

Ошибки AI, которые пришлось исправить вручную:

- предположение, что сегодняшний незавершённый день обнуляет серию;
- вставка пользовательского названия через небезопасный HTML;
- отсутствие ограничений размера API-запроса;
- слишком сложный первоначальный scope с авторизацией и облачной БД.

## 3. Вопросы — 5 минут

Короткие ответы:

- Почему не React? Для двухдневного MVP зависимости не давали функциональной выгоды; модули разделены так же явно, а запуск не требует установки пакетов.
- Почему localStorage? Это прямо соответствует заданию и позволяет проверить продукт без инфраструктуры.
- Как масштабировать? Добавить авторизацию, PostgreSQL/Supabase, синхронизацию и серверную историю аналитики.
- Как защищён ключ? Только server environment, `.gitignore`, API proxy, ни одной передачи ключа в браузер.
- Как проверено? Unit, integration, реальный desktop-сценарий в Chrome, адаптивные правила mobile и проверка консоли.
